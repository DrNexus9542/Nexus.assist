# Nexus.assist

### Ce projet est un assistant vocal capable d'effectuer des actions simples sur votre PC.

##### Fonctionalités actuelles :
- Wake word
- arrêt du programme

#### Fonctionalitées attendues//prévues :
- STT
- Comprehension IA (Qwen 2.5:3B)
- reconnaissance biométrique voix

## Dépendances :

- PyAudio
- pyTorch
- Ollama
- numpy
- openwakeword
- faster-whisper
- av version 19 (av<19)
